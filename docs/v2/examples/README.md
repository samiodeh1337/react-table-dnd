# react-table-dnd v2 examples (archived)

These are the demo sources that shipped with react-table-dnd 2.x, kept for users still on that major. Imports point at `react-table-dnd`; the TypeScript files also import `./example-data.ts` from this folder.

Current examples live in [`src/examples`](../../../src/examples) and run on the [docs site](https://samiodeh1337.github.io/react-table-dnd/).
